# RTS Game Design

Documentacion viva del juego RTS top-down para navegador, con campana persistente, batallas por slots y una arquitectura preparada para evolucionar de single-player a multiplayer casual.

## Estado actual

El proyecto esta en fase de diseno tecnico y definicion del vertical slice. El objetivo inicial es validar una version jugable en navegador con campana minima, organizacion de grupos, combate por slots de 5 segundos y control de zona.
